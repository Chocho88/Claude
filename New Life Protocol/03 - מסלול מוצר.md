# 🚀 מסלול מוצר — מתשתית/כלים → חשיבת מוצר

[[00 - מפת המסע|← חזרה למפה]]

> **סוג:** מסלול-זהות. כאן בעיית הפיזור הכי בוערת.
> ההבדל בין "תשתית/כלים" ל"מוצר": לא *לבנות עוד יכולת*, אלא לקחת דבר *אחד* עד משתמש אמיתי.

| רכיב | תוכן |
|------|------|
| **אנטי-חזון** (מה על הכף) | עוד שנה של עשרה פרוטוטייפים מתים ואפס מוצר שמישהו אמיתי משתמש בו. נשארת ה"איש תשתיות" שבונה יכולות לאחרים. |
| **חזון** (איך מנצחים) | אתה חושב-מוצר: לוקח דבר *אחד* עד משתמש אמיתי, מודד שימוש, ומתקן לפי משוב. |
| **הצהרת זהות** | "אני מהסוג של אנשים ששולח דבר אחד עד הסוף ומקשיב למשתמש, לא שמתחיל עשרה." |
| **מטרת שנה (המשימה היחידה)** | _מלא: מוצר/פיצ'ר אחד עם X משתמשים אמיתיים. בחר מספר._ |
| **פרויקט חודש (קרב הבוס)** | _מלא: מה הדבר האחד לבנות/לשלוח החודש?_ |
| **מנופים יומיים (Quests)** | (א) לדבר עם משתמש אחד / לאסוף אות שימוש (ב) לשלוח שינוי אחד שמשתמש יראה (ג) *לא* לפתוח כיוון חדש |
| **אילוץ (חוק המשחק)** | "כיוון מוצר אחד בכל פעם. כל רעיון חדש הולך ל-backlog, לא ל-IDE." |

## 🔁 לולאת הקיברנטיקה (החלק הכי מגובה-ראיות)
> מטרה → לבנות → **לחוש** → להשוות → לתקן
> שלב ה"חישה" הוא מה שמבדיל מוצר ממחקר.

1. **מטרה** — מה אמור לקרות?
2. **לבנות** — הדבר המינימלי שאפשר להראות למשתמש.
3. **לחוש** — מי המשתמש? מה האות שזה עובד (שימוש חוזר? המלצה?)
4. **להשוות** — מול המטרה.
5. **לתקן** — לשנות ולחזור.
